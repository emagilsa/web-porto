# Portfolio Website

Website portofolio pribadi — dibangun dengan HTML, CSS, dan JavaScript murni (tanpa framework/build tool).

## Struktur File
```
├── index.html      # Struktur halaman
├── style.css        # Semua styling
├── script.js         # Interaksi (scroll reveal, mobile menu, dll)
└── hero-photo.jpg  # Foto profil di hero section
```

## Cara Menjalankan
Buka `index.html` langsung di browser, atau jalankan local server:
```bash
npx serve .
```

## Deploy
Bisa langsung di-deploy gratis ke:
- [Vercel](https://vercel.com)
- [Netlify](https://netlify.com)
- [GitHub Pages](https://pages.github.com)
